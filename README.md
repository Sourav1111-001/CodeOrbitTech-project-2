# Tic-Tac-Toe with AI 🎮

A fully enhanced browser-based Tic-Tac-Toe game with an unbeatable AI opponent.

## Features

- **Minimax AI** with Alpha-Beta pruning — plays optimally on Hard mode
- **Easy / Hard** difficulty toggle
- **Scoreboard** — tracks You / Draw / AI wins across games
- **Animated X & O** symbols with spring pop-in effect
- **SVG win line** drawn across the board on victory
- **Glowing pulse** on winning cells
- **Sound effects** via Web Audio API (click, win, lose, draw)
- **Result overlay** with emoji after each game
- **Responsive** design — works on mobile too

## How to Play

1. Open `index.html` in any modern browser
2. You are **X**, AI is **O**
3. Click a cell to make your move
4. Try to beat the AI on Easy mode — Hard is unbeatable!

## Tech Stack

- HTML5
- CSS3 (animations, CSS variables, SVG)
- Vanilla JavaScript (no libraries)
